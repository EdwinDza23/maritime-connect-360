# MC360 Design System

## Design Philosophy
Create a timeless enterprise experience that still feels modern in 2035.

## Visual Direction
Inspired by the quality of Linear, Apple, Vercel, Stripe, Raycast and Framer while remaining original.

## Color
- Light theme
- Enterprise blue primary
- Electric cyan accents
- Indigo and ocean teal support
- Soft mesh gradients
- Atmospheric backgrounds

## Typography
- Large display headings
- Clear hierarchy
- Generous whitespace
- Premium modern sans-serif

## Layout
- Wide containers
- Bento layouts
- Broken grid compositions
- Large visual storytelling

## Components
- Floating navigation
- Interactive hero
- AI chatbot
- Solution cards
- Pricing cards
- Customer stories
- CTA sections

## Motion
- Smooth and cinematic
- Scroll storytelling
- Layered reveals
- Subtle parallax
- Premium hover states
- Magnetic buttons
- No bouncy animations

## Visual Effects
- Glass only where meaningful
- Soft shadows
- Layered depth
- Ambient lighting
- Mesh gradients
- Radial glows
- Subtle noise texture

## Product Cards
Each card should include:
- Live product preview
- Business value
- AI insight
- Feature chips
- Hover interaction

## Hero
- Interactive dashboard
- AI chat
- 3D maritime visualization
- Floating analytics
- Start Free Trial (primary)
- Book Demo (secondary)

## Accessibility
- High contrast
- Keyboard friendly
- Responsive
- Motion reduction support

## Never Do
- Template designs
- Flat layouts
- Excessive glass
- Repeated section patterns
- Decorative motion without purpose
